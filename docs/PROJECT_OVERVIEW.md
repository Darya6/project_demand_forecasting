# Обзор проекта по разработке система прогнозирования спроса для FMCG-ритейла

---

## Проблема и решение

**Проблема:** Розничные сети теряют 20-30% выручки из-за избыточных запасов и дефицита товаров

**Решение:** ML-система для автоматического прогнозирования спроса с точностью sMAPE ≤ 20%

**Эффект:** Снижение потерь на 15-25%

---
## Источники данных
Основной датасет:
[FMCG Daily Sales Data (2022-2024)](https://www.kaggle.com/datasets/beatafaron/fmcg-daily-sales-data-to-2022-2024) 

---

## Результаты

| Метрика | Целевое | Фактическое |
|---|---|---|
| **Точность (sMAPE)** | ≤ 20% | **18.4%** |
| **Время прогноза** | < 60 сек | **3-15 сек** |
| **Объем данных** | до 50 МБ | **1.2 млн записей** |

**Функционал:**
- Прогноз на 7-30 дней
- Сценарный анализ (изменение цены ±90%)
- 20 признаков
- Экспорт в 5 форматов

---

## Технологии

**ML:**
- Random Forest (scikit-learn) - прогнозирование
- TimeSeriesSplit - кросс-валидация
- GridSearchCV - оптимизация гиперпараметров
- OLS Regression - оценка эластичности

**Stack:**
- Python 3.11, pandas, numpy
- Streamlit - веб-интерфейс
- Plotly - интерактивные графики

---

## ML-пайплайн

### 1. Генерация признаков 
- Временные (4): day_of_week, month, is_weekend, quarter
- Лаговые (4): lag_1, lag_2, lag_7, lag_14
- Статистические (4): rolling_mean/std
- Сезонные (3): is_holiday_peak, is_summer, is_winter
- Динамические (2): momentum
- Ценовые (3+): price_lag, price_change_pct

### 2. Адаптивная стратегия
- **Один товар** → GridSearchCV (оптимизация) → 8-15 сек
- **Общий спрос** → фиксированные параметры → 3-5 сек

### 3. Валидация
TimeSeriesSplit (3 фолда, test_size=30 дней)
→ sMAPE по фолдам: [18.2%, 19.1%, 17.9%]
→ Среднее: 18.4%

# Тестовые файлы валидации
**Все файлы содержат ошибки** для проверки обработки

---
## Список файлов

### 1. `test_bad_dates.csv`
**Ошибка:** Некорректные форматы дат (`invalid_date`, `32.01.2024`, `2024-13-01`)

**Ожидается:**
Некорректный формат даты. Поддерживаемые: DD.MM.YYYY, YYYY-MM-DD
---
### 2. `test_missing_columns.csv`
**Ошибка:** Отсутствует поле `sales`

**Ожидается:**
Отсутствуют обязательные поля: ['sales']
---

### 3. `test_missing_product_id.csv`
**Ошибка:** Отсутствует `product_id`

---
### 4. `test_missing_date.csv`
**Ошибка:** Отсутствует `date`

---
### 5. `test_negative_sales.csv`
**Ошибка:** Отрицательные продажи (`-50`), дробные (`150.7`), отрицательные цены (`-5.00`)

**Ожидается:**
- Отрицательные продажи → 0
- Дробные → округление
- Отрицательные цены → NaN (с предупреждением)
---

### 6. `test_empty_product_id.csv`
**Ошибка:** Пустые ID (пустая строка, `NaN`)

**Ожидается:**
Обнаружены пустые идентификаторы товаров!
Количество: 2
---
### 7. `test_long_product_id.csv`
**Ошибка:** ID > 100 символов (127 символов)

**Ожидается:**
Слишком длинный идентификатор товара!
Максимум: 100 символов
---

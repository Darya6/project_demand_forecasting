# Требования к системе

## Бизнес-требования

### БТ1. Точность прогнозирования
- sMAPE ≤ 20% на тестовой выборке
- Доверительные интервалы ±20%

### БТ2. Поддержка решений
- Сценарный анализ «Что, если?» (цена ±90%)
- Оценка ценовой эластичности
- Время анализа ≤ 5 минут

### БТ3. Доступность
- Веб-интерфейс без установки ПО
- Понятные сообщения об ошибках
- Русский язык
---

## Функциональные требования

### ФТ1. Работа с данными
- Загрузка CSV до 50 МБ
- Валидация: `date`, `product_id`, `sales`
- Адаптация названий столбцов 
- Минимум 30 дней данных

### ФТ2. Прогнозирование
- Random Forest + TimeSeriesSplit
- GridSearchCV (один товар) / фиксированные параметры (общий спрос)
- Метрики: sMAPE, RMSE

### ФТ3. Сценарный анализ
- Оценка эластичности: `log(Sales) ~ log(Price)`
- Прогноз на 7-30 дней
- Изменение цены: -90% до +90%

### ФТ4. Экспорт
- Форматы: CSV, PDF, Excel, Word, ZIP
- Русские названия столбцов
- Метрики качества в отчетах

### ФТ5. Интерфейс
- Streamlit (боковая панель + основная область)
- Интерактивные графики (Plotly)
- Доверительные интервалы
---

## Нефункциональные требования

| Категория | Требование |
|---|---|
| **Точность** | sMAPE ≤ 20%, интервалы ±20% |
| **Производительность** | Прогноз ≤ 5 мин, файл ≤ 50 МБ |
| **Надежность** | Обработка ошибок без сбоев |
| **Совместимость** | UTF-8 CSV, автоопределение форматов |
| **Интерфейс** | Русский язык, понятные ошибки |

---
## Требования к данным

### Обязательные поля
- `date` - YYYY-MM-DD, DD.MM.YYYY
- `product_id` ≤ 100 символов
- `sales` целое ≥ 0

### Опциональные
- `price` > 0 (для сценарного анализа)

### Валидация
- Автоопределение формата даты
- Преобразование столбцов (quantity → sales, sku → product_id)
- Обработка отрицательных продаж (→ 0)
